CRM Lead Sequence

Add Sequence to lead records.

  • Overview
  • Features
  • Screenshots
  • Version

This module adds a dedicated automatic sequence number for CRM Leads in Odoo. Each lead is assigned a unique reference number when it is created, making leads easier to identify, track, and manage.

The sequence includes a date-based format with year and month, providing a clear reference to when the lead was created.

  • Automatic Lead Sequence Generation
  • Applicable Only on CRM type Lead
  • Lead Sequence is based on date reference
  • Unique Lead Identification
  • Applicable on list view, form view, search view and kanban view in lead
